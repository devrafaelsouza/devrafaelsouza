Olá! Eu sou Rafael Souza, estudante de Desenvolvimento de Sistemas e desenvolvedor em formação, apaixonado por tecnologia e por transformar ideias em soluções através da programação.

Atualmente, meu principal foco está em Java e desenvolvimento Back-End, enquanto aprofundo meus conhecimentos em Programação Orientada a Objetos, lógica de programação, bancos de dados, SQL, Git e desenvolvimento de sistemas.

Gosto de aprender na prática, criando projetos e enfrentando novos desafios que me fazem evoluir como programador. Cada projeto é uma oportunidade de colocar o conhecimento em prática, experimentar novas tecnologias e melhorar minhas habilidades.

Meu objetivo é construir uma carreira sólida na área de tecnologia, evoluindo continuamente e, no futuro, atuar no desenvolvimento de sistemas robustos, eficientes e bem estruturados.
